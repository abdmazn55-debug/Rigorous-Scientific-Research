
# Rigorous Scientific Research - 250M+ Papers

Next.js 14 project with 35 pages, searches 250M+ papers from OpenAlex, Semantic Scholar, arXiv, PubMed, CORE.

## Features
- Search 250M+ with PDF download
- 35 SEO optimized pages
- API: /api/search?q=&page=
- Download proxy: /api/download?url=

## Run
npm install
npm run dev
